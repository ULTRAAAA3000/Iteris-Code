# Шаблон курса: как сделать курс другого языка «как Go»

> Для кого: для того, кто пишет курс (человек или сессия Claude). Цель: **не писать каждый курс с нуля**, а взять готовый каркас (структуру, нормы, шаблоны, проверки), наполнить его материалом своего языка и пройти по шагам.
> Образец: курс Go (110 уроков, 12 глав, 110 заданий). Как писать сами уроки и задания Go: [go-course-authoring.md](go-course-authoring.md). Как запускаются и проверяются задания: [task-runtime.md](task-runtime.md). Порядок этапов: [main-plan.md](main-plan.md), стратегия запуска: [launch-strategy.md](launch-strategy.md).
> Все цифры в разделе 1 **измерены на реальном курсе Go в `main` (110 уроков)**, а не придуманы. Остальное (планы глав других языков) это стартовые предложения: перед написанием план каждого языка уточняет автор.
> Последнее обновление: 18.11.2026.

## 0. Быстрый старт: девять шагов

1. **Выберите язык и прочитайте его лист** в разделе 3: тип курса (A–E), как запускается код, ограничения песочницы, подводные камни, что уже есть на сайте.
2. **Зафиксируйте версию языка** (какой компилятор у запуска и какие возможности версии вы обещаете ученику). Разница версий уже один раз испортила уроки Go (раздел 9).
3. **Составьте план** `content/<язык>/chapters.js`: 12 глав, 110 уроков, 30 из них `adv`. Берите карту глав языка из раздела 3 и «слоты» Go из раздела 2 (каждому уроку Go соответствует урок вашего языка).
4. **Скопируйте тестовый стенд** `tests/go-tasks.test.mjs` и подключите запуск настоящим компилятором (команды в разделе 6). Пока курс пишется, пользуйтесь режимом «частично» (`<ЯЗЫК>_CH=05`, `<ЯЗЫК>_PARTIAL=1`).
5. **Пишите по главам, по порядку**: урок, затем задание, затем эталон, затем запуск главы настоящим компилятором. Закончили главу: коммит `<Язык> course: chapter NN complete`.
6. **Прогоните весь курс** настоящими инструментами (локально, в песочнице агента или в CI), поправьте всё, что показала проверка.
7. **Перечитайте курс глазами ученика**: порядок тем, зависимости базовых уроков от продвинутых, тон, ошибки в объяснениях.
8. **Подключите курс к сайту** (раздел 4, шаг 7) и пройдите по одному заданию в каждой главе на живом сервисе запуска.
9. **Допишите в этот документ**, что узнали (лист языка, подводные камни): следующий курс должен идти быстрее.

## 1. Стандарт: что значит «как Go»

### 1.1 Формат и объём

| Параметр | Значение (Go, измерено) |
|---|---|
| Уроков в курсе | **110**, сквозная нумерация `<язык>/1` … `<язык>/110` |
| Глав | **12** |
| Базовый уровень | **80** уроков |
| Просунутый уровень | **110** уроков = 80 базовых + **30** с флагом `adv: true` (27%) |
| Практических заданий | **110**: ровно одно на каждый урок |
| Вопросов самопроверки | **2** на каждый урок (отдельно от практического задания) |
| Текста уроков всего | ≈ **73 400 слов** (простыми словами, теория, «запам'ятайте», «як в роботі», вопросы самопроверки; без постановок заданий), в среднем **667 слов на урок** |
| Кода в уроках | ≈ **12 700 строк** в 400 запускаемых программах (в среднем 116 строк на урок) |
| Эталонов заданий | ≈ **5 100 строк** кода |
| «Пастки» в примерах | из 400 программ **43** намеренно не компилируются, **29** намеренно падают, **7** только собираются: примерно **каждый пятый** пример показывает ошибку |

Для 12 других языков при той же планке это ≈ **1 170 уроков** и около **780 000 слов** теории: это не «довычитать пару уроков», а полноценное производство. План по очерёдности и оценка объёма в разделе 10.

### 1.2 Нормы урока

Поля урока и их назначение описаны в [go-course-authoring.md](go-course-authoring.md), раздел 3. Ниже нормы для нового курса и то, что реально получилось в Go (минимум / медиана / 90-й процентиль, по 110 урокам).

| Поле | Норма | Go: мин / медиана / p90 |
|---|---|---|
| `t` (название) | точно как в плане `chapters.js` | |
| `easy` («Простими словами») | 1–2 предложения, бытовая аналогия, **20–50 слов** | 21 / 33 / 46 |
| `p` (теория) | **6–7 абзацев**, не менее 1 800 символов суммарно | абзацев 6 / 7 / 7; символов 1 978 / 3 398 / 4 233; слов 321 / 514 / 649 |
| `code` (примеры) | **3–5 блоков**, от простого к реалистичному; программа запускается и даёт предсказуемый вывод | блоков 3 / 4 / 4; строк на урок 25 / 104 / 187 |
| `note` («Запам'ятайте») | главное правило или ловушка, **18–60 слов** | 18 / 34 / 47 |
| `work` («Як це в роботі») | где это встречается в реальных проектах, **28–60 слов** | 28 / 39 / 48 |
| `tasks` (самопроверка) | **ровно 2** вопроса | 2 / 2 / 2 |
| Итого слов на урок | ориентир **450–950** | 445 / 649 / 828 |

**Как учить, а не пересказывать** (шесть шагов): зачем, модель в голове, примеры по ступенькам, ловушки, идиомы, связь со следующим уроком. Подробно в [go-course-authoring.md](go-course-authoring.md), раздел 3. Из этого следует правило глубины: **в каждом уроке есть хотя бы один показанный сбой** (ошибка компиляции, исключение, неправильный результат) там, где у темы есть типичные ловушки. В Go такие маркеры стоят примерно в каждом пятом примере.

### 1.5 Базовый и просунутый уровень

- **Базовый (80 уроков)**: всё, что нужно, чтобы начать работать на языке. **Просунутый (110)**: базовые плюс 30 уроков с `adv: true`. Пользователь переключает уровень в любой момент, прогресс не теряется.
- **Правило зависимостей.** Базовый урок опирается только на более ранние **базовые**. Просунутый может опираться на базовые и на более ранние просунутые. Если базовому нужна вещь из просунутого, он вводит её сам, коротко.
- Где у Go стоят `adv` (по главам): 0, 2, 3, 2, 4, 2, 4, 4, 2, 2, 3, 2. То есть в каждой главе, кроме первой, 2–4 просунутых урока: оптимизации, внутреннее устройство, редкие API, проектирование.
- **Статус на сайте:** флаг `adv` пока есть только в данных курса Go. Переключатель уровня в интерфейсе ещё не реализован (в `src/` нет обработки `adv`), его делают один раз для всех курсов при подключении Go.

### 1.7 Оформление урока на странице

Один шаблон для всех курсов: `src/lesson-body.ts` (разметка) и `src/lesson.css` (стили, класс `.l-body`). Автору курса ничего делать не нужно: поля урока (`easy`, `p`, `code`, `note`, `work`, `tasks`) подставляются в шаблон сами, тексты не меняются.

- Сверху «Простими словами», затем чипы-оглавление (Теория, Примеры, Запам'ятайте, У роботі, Самоперевірка), в мета-строке время чтения (≈ слов / 180).
- Разделы пронумерованы, первый абзац теории крупнее, между абзацами увеличен интервал, `<code>` и `<b>` выделены.
- Примеры стоят прямо в тексте теории, а не отдельным блоком в конце: пример идёт за абзацем, который его объясняет. Привязка автоматическая (`placeExamples`): для каждого примера берётся абзац, где в тегах `<code>` встречается больше всего его фрагментов; порядок примеров сохраняется, примеры без совпадений распределяются равномерно. Поэтому в абзаце стоит писать `<code>` ровно тот фрагмент, который потом виден в примере (например `var age int = 17`), и тогда пример встанет под ним.
- Длинные абзацы автоматически делятся по предложениям на 2-3 части с малым промежутком между ними (`splitParagraph`): текст тот же, но стена текста разбита. Тег `<code>` с точками внутри и сокращения («т. д.», «напр.») не разрезаются.
- Над текстом кнопки A− / A+ (`src/fontsize.ts`, 4 шага, выбор запоминается в браузере).
- Каждый пример подписан «Приклад N з M». Если первая строка примера начинается с комментария с маркером (`не компілюється`, `аварія`, `лише компіляція`, `фрагмент`, см. раздел 3.1), у примера появляется цветная метка. Маркер надо писать именно первой строкой блока.
- Проверка шаблона: `node tests/lesson-body.test.mjs` (текст не искажён, структура у всех уроков Go и Python одинакова).

### 1.6 Глубина важнее числа

110 уроков это цель, а не повод растягивать. Если у языка нет материала на 110 уроков без воды, остановитесь там, где перестаёт выполняться норма из 1.2: **минимум 80 базовых уроков** (запуск по launch-strategy), остальное это просунутый хвост. Признаки воды: урок на 300 слов, пример без вывода, задание «напечатайте строку», дублирование предыдущего урока. Каждый урок отвечает на вопрос: **чему человек научится нового и что напишет сам**.

## 2. Скелет: 12 глав-слотов

Курс делится на 12 глав одинаковой ролью, у каждой есть размер и число `adv`. **Каждый урок Go это «слот»**: его название, размер, роль в главе. При планировании нового языка берите слот и ищите настоящий аналог в языке, а не копируйте тему буквально (у Python нет указателей, у Bash нет интерфейсов).

| № | Роль главы (универсальная) | Уроков | adv | Что в Go |
|---|---|---|---|---|
| 01 | Старт: установка, первая программа, пакеты/модули, инструменты | 4 | 0 | go install, Hello, пакеты, `go fmt`/`go vet` |
| 02 | Основы языка: переменные, типы, строки, ввод-вывод, условия, циклы, функции | 14 | 2 | var и `:=`, числа, константы, строки/руны, `strconv`, `fmt`, `if`/`switch`/`for`, замыкания, рекурсия |
| 03 | Коллекции: массивы, списки, словари, множества, сортировка | 12 | 3 | массивы, слайсы, мапы, `range`, `sort`, `slices`, `maps` |
| 04 | Типы пользователя: структуры/классы, методы, ссылки и память | 9 | 2 | структуры, указатели, методы, встраивание, `iota`, теги, escape analysis |
| 05 | Абстракция: интерфейсы/протоколы, обобщения, типовая система | 12 | 4 | интерфейсы, `any`, type switch, generics, `reflect` |
| 06 | Ошибки: ошибки как значения/исключения, ресурсы, стратегии | 7 | 2 | `error`, `%w`, `errors.Is/As`, `defer`, `panic`/`recover` |
| 07 | Параллелизм: потоки/задачи, синхронизация, таймеры | 15 | 4 | горутины, каналы, `select`, `sync`, `context`, worker pool, race, память |
| 08 | Стандартная библиотека: строки, время, JSON, regexp, логи, файлы | 12 | 4 | `strings`, `bufio`, `time`, `encoding/json`, `regexp`, `slog`, `os`, `io/fs` |
| 09 | Тестирование и качество | 6 | 2 | пакеты, табличные тесты, моки, бенчмарки, fuzzing, ловушки линтеров |
| 10 | Сеть и сервисы | 8 | 2 | `net/http`, `httptest`, маршруты, JSON API, middleware, клиент, graceful shutdown |
| 11 | Архитектура | 6 | 3 | слои, DI, in-memory хранилище, конфигурация, `database/sql`, логи |
| 12 | Проекты: связать всё в законченные программы | 5 | 2 | анализ текста, REST API заметок, конкурентный обработчик, кеш с TTL, rate limiter |
| | **Итого** | **110** | **30** | |

**Правила переноса слота:**

1. **Размер главы можно двигать в пределах ±3 урока**, если в языке тема глубже или беднее, но сумма остаётся 110 и `adv` 30.
2. **Роль главы менять нельзя**, но содержание можно: «Параллелизм» в PHP превращается в «Генераторы, итераторы, Fibers» (см. лист PHP), «Сеть и сервисы» в языке без сети строится на разборе протоколов и тестах обработчиков без сокетов.
3. **Практика в конце главы.** В Go в главе коллекций есть урок «Практика: частотный словарь» (`go/30`), а глава 12 целиком проектная. Закрепляющий «практический» урок в 1–2 главах помогает держать темп.
4. **Одна новая идея на урок.** Если урок вводит два новых понятия, разделите.
5. **Урок не опирается на будущее.** О будущей теме можно упомянуть одним предложением («про это в главе об ошибках»), но пример на ней не строить.

Полный список 110 уроков Go (образец для слотов) приведён в Приложении A в конце документа.

**Какой компилятор у запуска.** Версию определяет `lib/runners.ts`: Go идёт через Go Playground (`go.dev/_/compile`), остальные языки через Wandbox, а компилятор выбирается из его списка по шаблону имени (`cpython-3.*`, `openjdk-*`, `gcc-<цифра>*`, `php-<цифра>*`, `fpc-*`, `typescript*`, `sqlite*`, `bash*`). Версии могут обновляться без нашего участия, поэтому перед работой посмотрите, что именно выбралось, и назовите версию в курсе.

Старые короткие курсы не выбрасываются: у них есть `keep`, то есть `id` старых заданий переезжают на подходящий новый урок (как в Go), прогресс пользователей сохраняется.

**Маркер намеренной ошибки в других языках.** В Go маркер стоит первой строкой блока: `// не компілюється: …`, `// аварія: …`, `// лише компіляція: …` (регулярки тестового стенда ищут эти слова). В другом языке то же самое слово ставится после **комментария этого языка**: `#` (Python, Bash), `//` (Java, C++, PHP, Pascal, TypeScript, JavaScript), `--` (SQL), `/* … */` (CSS), `<!-- … -->` (HTML). У языков без явной «компиляции» (Python, PHP, Bash) слова «не компілюється» означают синтаксическую ошибку, а «аварія» исключение времени выполнения. Блок без маркера должен завершиться успешно. Отрывки, которые не надо запускать (команды терминала, фрагменты), помечайте первой строкой `фрагмент:` (у Go вместо этого признак «нет `package main`»).

- Ветка `feature-<язык>-course-levels`, коммиты `<Язык> course: chapter NN complete` (допустимы промежуточные `chapter NN lessons A–B`).
- Пока курс не закончен, в PR пишите `WIP` и не подключайте к сайту.
- **Подтягивайте `main` в ветку не реже раза в несколько дней.** Ветка курса Go к моменту слияния отставала от `main` на 97 коммитов; слияние прошло чисто только потому, что курс лежит в отдельных файлах.

## 6. Проверка настоящими инструментами

Структура урока проверяется без инструментов, **поведение кода нет**: пока примеры и эталоны не запущены настоящим компилятором, курс считается непроверенным.

### 6.2 CI

CI уже запускает `npm test` на `ubuntu-latest` (`.github/workflows/ci.yml`). Тест по каждому языку **молча пропускает язык, если инструмента нет** (проверка `probe`): зелёный CI может означать «ничего не проверено». Рекомендации:

1. Добавьте в CI шаги установки нужного (`sudo apt-get install -y fp-compiler` для Pascal; для остальных сначала посмотрите, что уже есть на раннере).
2. Добавьте переменную `REQUIRE_TOOLS=1`: при ней тест **падает**, а не пропускает язык без инструмента.
3. Тест курса Go (`tests/go-tasks.test.mjs`) сейчас не входит в `npm test`; верните его в CI, когда курс подключён.

### 6.3 Установка инструментов в песочнице агента

Сеть песочницы ограничена списком адресов (среди них `conda.anaconda.org`, `github.com`, `pypi.org`, `registry.npmjs.org`). Проверено 18.11.2026:

```bash
# micromamba с GitHub, затем PHP, JDK и SQLite из conda-forge
curl -L -o micromamba https://github.com/mamba-org/micromamba-releases/releases/latest/download/micromamba-linux-64
chmod +x micromamba && export MAMBA_ROOT_PREFIX=/opt/mm
./micromamba create -y -q -p /opt/tc -c conda-forge --override-channels php openjdk sqlite
export PATH=/opt/tc/bin:$PATH      # получилось: PHP 8.5, javac 25, SQLite 3.54
```

Go в conda-forge есть (`go`, сборка `nocgo`, 60 МБ): проверен **ручной** способ (скачать `.conda` с `conda.anaconda.org`, распаковать `pkg-*.tar.zst` через `zipfile` и `zstandard`, указать `GOROOT`). Установка через `micromamba create -p /opt/go -c conda-forge go` должна работать так же, но отдельно не проверялась.

**Не ставится:** Free Pascal (в conda-forge нет, зеркало Ubuntu закрыто для `apt`). Предустановлены: `g++`, `python3`, `node`, `bash`, `git`; Java есть только JRE (`javac` нужно поставить, как выше).

### 6.4 Практические уроки, из-за которых тратилось время

- **Одно ядро и 4 ГБ памяти.** Стенд запускает сборки пулом: на холодном кэше шесть одновременных сборок не укладываются в таймаут 60 секунд. **Сначала прогрейте кэш** (запустите пустую программу или одну главу), потом гоняйте остальное. Главы запускайте **по одной**.
- **Долгие проверки запускайте отдельным процессом** (`setsid nohup скрипт &`, лог в файл) и опрашивайте лог; фоновые процессы из вызова инструмента могут обрываться.
- **Не используйте `pkill -f` с шаблоном, который есть в вашей же команде**: убьёте собственную оболочку.
- **Пустой `stderr` и общее сообщение «очікувалась аварія…» почти всегда означает таймаут** (процесс убит, код выхода `null` считается как 1). Перезапустите главу, прежде чем искать ошибку в содержании.
- Для компилятора важно **изолированное окружение** (отдельные `GOCACHE`, без `go.mod`): тесты Go используют `GO111MODULE=off`.

## 7. Как раздавать работу сессиям Claude

- **Единица работы: одна глава** (до 15 уроков) на сессию. Языки независимы, поэтому можно вести несколько языков параллельно, но запуск и CI общие: следите за нагрузкой.
- **Что передать сессии:** этот документ, [go-course-authoring.md](go-course-authoring.md), [task-runtime.md](task-runtime.md), лист языка (раздел 3), готовый `chapters.js`, **одну готовую главу Go как образец стиля** (например, `content/go/ch04.js` с заданиями и эталонами) и стенд.
- **Правила сессии:** одна глава за раз; не трогать чужие языки и общий код; после главы запустить тест главы настоящим компилятором; закоммитить; в конце сообщить, что проверено запуском, а что нет.
- **Ревью владельца:** по 2 урока из главы (выборочно), прежде чем запускать следующую главу.

## 8. Чек-листы

**Урок.** Название как в плане. Одна новая идея. `easy` живая аналогия. 6–7 абзацев теории: зачем, модель в голове, ловушки, идиомы. 3–5 примеров по ступенькам, каждый запускается (кроме помеченных `фрагмент`). Есть показанный сбой с маркером там, где у темы есть ловушки. `note` и `work` написаны. Ровно 2 вопроса самопроверки. Нет опоры на будущие уроки. Базовый не зависит от `adv`.

**Задание.** Одно на урок, id уникален. Заготовка запускается и **не** проходит всех проверок. Эталон проходит все. ≥3 проверки, из них вывод (`has`/`equals`); `source`-проверка только если нужна конструкция урока. Есть `hint` у проверок. Проверки не зависят от времени, случайности, порядка. XP соответствует сложности. `context` отвечает на «зачем».

**Глава.** Размер как в плане. Порядок уроков логичен. Один-два закрепляющих урока. Тест главы зелёный настоящим инструментом. Средние слова на урок и число проверок в нормах раздела 1.4.

**Курс.** 12 глав, 110 уроков, 30 `adv`, 110 заданий. Все главы проверены настоящим инструментом **той версии, что у запуска**. CI зелёный и **не пропускает** язык. Подключено к сайту, старые `id` заданий (`keep`) сохранены. «Що нового» и документация обновлены.

## 9. Подводные камни (уже встретились)

1. **Версия языка уходит вперёд.** При проверке Go 1.27.4 два урока Go (go/35 «Вбудовування і композиція», пример 4, и go/48 «Generics: типи й обмеження», пример 4) утверждают, что код не компилируется, а он компилируется: в новой версии разрешены продвинутые поля в литерале структуры и параметры типа у методов. Инструкция при этом говорит «Go 1.24». Правило: **проверять примеры компилятором той же версии, что у запуска, и перепроверять курс при смене версии**; в уроках называть версию, с которой возможность появилась.
2. **Тест молча пропускает язык без инструмента** (раздел 6.2).
3. **Таймауты на холодном кэше** и вводящее в заблуждение сообщение об «аварии» (раздел 6.4).
4. **Ветка курса отстаёт от `main`** (97 коммитов у Go). Подтягивайте `main`.
5. **«Курс готов» не значит «курс на сайте».** Содержимое Go лежит в `content/go`, а сайт показывает старые 11 уроков. Считайте задачу законченной после шага 7–8.
6. **Недетерминизм вывода.** Порядок `set` строк в Python, `HashMap`/`HashSet` в Java, `unordered_*` в C++, строки SQL без `ORDER BY`, `ls` и глоб в Bash, `git log` с хэшами и датами. Всегда сортируйте и фиксируйте.
7. **Кодировка вывода Java** (только ASCII в stdout), кириллица в строках Pascal (это байты), `UPPER` в SQLite.
8. **Внешний сервис запуска может измениться.** Публичный сервис Piston перестал быть бесплатным с 15.02.2026, поэтому используется Wandbox, а компилятор берётся из его списка (`list.json`). Версии у разных языков могут обновляться без нашего участия: см. камень №1.
9. **Задания про DOM и события для JS пока нельзя сделать** (нет безопасной песочницы), и layout-задания CSS нельзя проверять по размерам (раздел 3.3).
