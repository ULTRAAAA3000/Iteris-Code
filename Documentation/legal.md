## 1. Решения

- **Оператор данных:** чешская компания владельца. Применяется GDPR и чешский закон о защите данных; надзорный орган: ÚOOÚ (Úřad pro ochranu osobních údajů). Украинские пользователи тоже защищены GDPR, пока оператор в ЕС.
- **Язык сайта не мешает.** Сайт на украинском, потом на английском: тексты должны быть на языке пользователя. Поэтому: политика и условия публикуются **на каждом языке интерфейса**. **Основным будет английский текст** (решение владельца): сайт по умолчанию на английском, сверху переключатель на украинский. Перевод делаем после написания всех уроков ([mvp.md](mvp.md)); до этого главный украинский текст.
- **Возраст (решено владельцем):** 15+. При регистрации по почте спрашиваем возраст (число); меньше 15 — отказ с сообщением. Возраст **не сохраняем**. Для входа через Google/GitHub под кнопками написано, что продолжая человек подтверждает 15+ и принимает условия. До 18 лет — с согласия родителей (в условиях).
- **Cookie:** сейчас только технический cookie сессии (согласие не нужно, но сообщить нужно). Баннер выбора нужен **до рекламы и аналитики** (этап 6).

## 2. Какие данные собираем (по коду)

| Данные | Зачем | Где |
|---|---|---|
| Email, имя, фото из Google/GitHub | вход, кабинет | D1 |
| Хеш пароля (вход по почте) | вход | D1 |
| XP, уровень, серия, пройденные уроки и задания, код решений | прогресс | D1 |
| Ник, герой-аватар, био, публичность профиля | публичный профиль (по выбору пользователя) | D1 |
| Cookie сессии | вход | браузер |
| Тема, язык, настройки интерфейса | удобство | localStorage |
| IP и технические логи | безопасность, лимиты | Cloudflare |
