# Юридические документы: политика конфиденциальности, условия, cookie

> **Черновик** (17.11.2026). Я не юрист: тексты нужно показать чешскому юристу или бухгалтеру компании до запуска маркетинга ([mvp.md](mvp.md), блок «Доверие и закон»). Тексты: [legal/privacy.uk.md](legal/privacy.uk.md), [legal/terms.uk.md](legal/terms.uk.md).

## 1. Решения

- **Оператор данных:** чешская компания владельца. Применяется GDPR и чешский закон о защите данных; надзорный орган: ÚOOÚ (Úřad pro ochranu osobních údajů). Украинские пользователи тоже защищены GDPR, пока оператор в ЕС.
- **Язык сайта не мешает.** Сайт на украинском, потом на английском: тексты должны быть на языке пользователя. Поэтому: политика и условия публикуются **на каждом языке интерфейса**. Для споров главным считается английский (когда появится), украинская версия — перевод; это нужно записать в условиях (уже записано).
- **Возраст:** в Чехии возраст цифрового согласия 15 лет. Платформа учебная, подростки среди пользователей. Решение в черновике: **15+; младше 18 — с согласия родителей**. Проверить с юристом.
- **Cookie:** сейчас только технический cookie сессии (согласие не нужно, но сообщить нужно). Баннер выбора нужен **до рекламы и аналитики** (этап 6).

## 2. Какие данные собираем (по коду)

| Данные | Зачем | Где |
|---|---|---|
| Email, имя, фото из Google/GitHub | вход, кабинет | D1 |
| Хеш пароля (вход по почте) | вход | D1 |
| XP, уровень, серия, пройденные уроки и задания, код решений | прогресс | D1 |
| Ник, герой-аватар, био, публичность профиля | публичный профиль (по выбору пользователя) | D1 |
| Cookie сессии | вход | браузер |
| Тема, язык, настройки интерфейса | удобство | localStorage |
| IP и технические логи | безопасность, лимиты | Cloudflare |

## 3. Внешние сервисы (обработчики), которые нужно указать

Cloudflare (хостинг, база D1, Turnstile), Google и GitHub (вход), Resend (письма), Go Playground и Wandbox (**код пользователя отправляется на их серверы для запуска**, об этом надо предупреждать), позже: платёжная система, реклама, аналитика.

## 4. Что нужно от владельца для заполнения

- Полное название компании, IČO, адрес, email для вопросов о данных, сайт.
- Подтвердить возраст (15+ / 16+ / 18+).
- Страна суда/право в условиях (по умолчанию право Чехии).
- Нужен ли DPO (для малого проекта обычно нет; решить с юристом).
- Хранение данных и срок: предложено «пока есть аккаунт + 30 дней после удаления».
- Кто отвечает на запросы пользователей (доступ, выгрузка, удаление).

## 5. Что нужно сделать в коде

- Страницы `/privacy`, `/terms` (в реестре `src/pages.ts`, индексируемые), ссылки в подвале и в форме входа («Продолжая, вы принимаете…»).
- Удаление аккаунта и выгрузка данных (требование GDPR).
- Согласие на cookie перед рекламой/аналитикой (этап 6).
- Версия документа и дата, запись о принятии при регистрации (по желанию).
