# Iteris Code: описание платформы

> Этот файл описывает, **какой продукт мы строим и как им пользуется человек**. Обновляется после каждого этапа.
> Порядок работ и подробности этапов: [main-plan.md](main-plan.md).
> Последнее обновление: 14.11.2026.

## Что это

**Iteris Code** — бесплатная платформа, на которой можно выучить язык программирования так, чтобы потом работать. Не абстрактные задачи, а практика ближе к реальным проектам: получаешь ТЗ и делаешь небольшой продукт.

**Главная мысль:** полностью бесплатно выучить язык до рабочего уровня. Платформа не должна быть «на миллион»: комфортная, понятная, лёгкая в рекламе.

## Принципы

1. **Бесплатно.** Весь учебный материал открыт.
2. **Работа, а не оценки.** Каждый урок показывает, как тема выглядит в реальном проекте («Як це в роботі»).
3. **Практика после теории.** После нескольких уроков человек делает мини-задания и проект по ТЗ.
4. **Свободный путь.** Любой урок доступен в любой момент. Платформа лишь рекомендует, с чего начать.
5. **Без ИИ-проверок.** Проекты проверяются автоматическими тестами по понятным требованиям.
6. **Простота.** Короткие объяснения, понятные аналогии, код блоками.

Все 30 старых id заданий сохранены (`keep`), прогресс не теряется. Проекты Python (`py-gradebook`, `py-inventory`, `py-bank`) переехали на уроки 52, 78 и 53 нового курса. Запуск заданий через Wandbox (`gcc`, `lib/runners.ts`: компилятор выбирается по точному названию языка, чтобы C не путался с C++). Pascal скрыт с лендинга флагом `landingHidden` в `src/data.ts` (счётчики, чипы и FAQ главной считают только видимые курсы), в каталоге и кабинете остаётся.
- **26.11.2026.** Админка `/admin` расширена: блок «Что изучают» (по каждому языку: сколько человек выбрали его в онбординге, сколько реально учатся, пройдено уроков, на продвинутом уровне), распределения по уровню старта, дневной цели и способу входа, активность за 1/7/30 дней, отправки заданий и доля успешных, обращения в поддержку. Данные считаются из существующих таблиц, новых миграций нет (`lib/stats.ts`, `lib/admin-users.ts`, `src/admin.ts`).
- **24.11.2026.** Курс SQL (35 уроков, 10 глав, 30 базовых + 5 просунутых) подключён к сайту по образцу HTML и Go: `content/sql/index.js` (`SQL_LESSONS`), `content/tasks/sql/index.ts` (`SQL_TASKS`), старые 15 уроков удалены из `content/lessons.js`, в `src/data.ts` `sql: { lessons: 35, base: 30 }`. Все 15 старых id заданий сохранены. Реальный прогон на `sqlite3` 3.45.1: 23 проверки, 210 запусков.
- **Курсы** (14): Python, Go, Java, C, C++, Pascal, HTML, CSS, JavaScript, TypeScript, PHP, SQL, Git, Bash. Всего 626 уроков, разбитых на главы (Python, Go, C и C++ по 110 уроков, HTML 30, CSS 40, SQL 35; у всех есть переключатель уровня).
- **Урок в едином формате** с короткой аналогией и разделом о реальной работе.
- **Практику прямо в уроке:** редактор кода, терминал результатов, автоматическая проверка (без установки чего-либо). JavaScript выполняется в браузере, Go на сервере; устройство и порядок подключения других языков описаны в [task-runtime.md](task-runtime.md).
- **Личный кабинет:** прогресс по курсам, карта навыков, серия дней, график активности, последние ответы.
- **Работу на телефоне:** все страницы проверены на экранах 360–414 px.

## Мотивация

- **XP и уровни:** прогресс, XP не тратится.
- **Серия и календарь:** «сколько я сегодня прошёл», анимация огня.
- **Монеты и магазин:** монеты тратятся; в будущем задел под заработок. За деньги монеты не продаются.
- **Профиль:** можно показать прогресс друзьям и работодателям.

## Как платформа будет зарабатывать (позже)

Сейчас всё бесплатно. Позже, когда будет аудитория: лёгкая реклама и/или небольшие подписки с «приятными плюшками». Платёжная система пока не выбрана.

## Технологии (коротко)

- Сайт: TypeScript, сборка esbuild, Cloudflare Pages.
- Сервер: Cloudflare Pages Functions, база Cloudflare D1.
- Вход: Google OAuth (GitHub будет добавлен).
- Код JavaScript выполняется в Web Worker на устройстве пользователя; код остальных языков запускается на сервере во внешней песочнице (сейчас Go через Go Playground), результат проверяет сервер.

## Глоссарий

| Термин | Значение |
|---|---|
| **XP** | Очки опыта за учёбу. Не тратятся, определяют уровень. |
| **Монеты** | Валюта для магазина. Тратятся. |
| **Серия** | Сколько дней подряд человек учился (по времени UTC). |
| **Путь** | Линейка уроков по главам для выбранного языка. |
| **Проект по ТЗ** | Небольшой продукт по заданным требованиям, проверяется автоматически. |
| **Мини-задание** | Короткое задание с кодом и тестами после урока. |
