# Герои платформы (айдолы)

Одиннадцать персонажей Iteris Code. Это наши символы: с ними пользователь знакомится на сайте, их можно выбрать аватаркой профиля, а в будущем они станут «лицами» разных частей платформы. Решение D19 в [main-plan.md](main-plan.md).

Картинки лежат в `static/idols/`: `<id>.webp` (320 px, для кружков) и `<id>-og.jpg` (600 px, для карточек в мессенджерах). Список и данные для кода: `src/data/idols.ts` (имя, цвет фона, описание внешности).

**Роли выше — черновые.** Они нужны, чтобы у каждого героя была своя «профессия», и мы их ещё обсудим вместе, прежде чем что-то делать. Пока герои работают только как аватарки.

## Где герои уже используются

- Аватарка профиля: выбор в настройках `/profile`, показ в шапке сайта, в кабинете и в публичном профиле `/u/<ник>`.
- Картинка для превью ссылки на профиль (Open Graph): герой владельца профиля.
- Если герой не выбран, публичный профиль показывает героя по умолчанию: он считается из ника, поэтому всегда один и тот же.
- Имена героев нельзя занять как ники (зарезервированы).

## Как добавить или заменить героя

1. Положить `<id>.webp` (320×320) и `<id>-og.jpg` (600×600) в `static/idols/`.
2. Добавить запись в `IDOLS` в `src/data/idols.ts` (id латиницей, имя, цвет фона, описание).
3. Добавить имя в зарезервированные слова в `lib/profile.ts` и строку в таблицу выше.
4. Запустить `npm test`: тест проверяет, что у каждого героя есть обе картинки.

Выбранный герой хранится по `id` (поле `avatar_id`), поэтому **id менять нельзя**, а убирать героя только если готовы сбросить выбор тем, кто его взял (такие профили покажут героя по умолчанию).

## Замена картинок

Файлы кэшируются на сутки (`/idols/*` в `_headers`). После замены `static/idols/<id>.webp` увеличьте `IDOL_IMG_V` в `src/data/idols.ts`, иначе часть пользователей ещё день будет видеть старую картинку. Картинки для аватарок должны быть квадратными (320×320): широкий оригинал обрезается по центру, а не сжимается (так исправлены Лімо и Ноа). `-og.jpg` (600×600) обновляйте вместе с ними, а в Telegram/мессенджерах кэш превью сбрасывается отдельно.
