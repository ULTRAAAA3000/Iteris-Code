## 2. Версія мови й середовище

- **Стандарт C++17.** Пісочниця збирає gcc без прапорців, локальний тест: `g++ -std=c++17 -O0 -pthread`. Можливості C++20/23 (концепції, `std::format`, діапазони, `<=>`, корутини) показуйте **лише** блоками з першим рядком `// фрагмент: C++20 …` (вони не запускаються) і лише в `adv`-уроках; у тексті називайте стандарт, з якого з'явилась можливість.
- **Приклади й еталони мають збиратися без попереджень** (`-Wall -Wextra`) і без порушень `-fsanitize=undefined`. Тест це перевіряє.
- Немає stdin і мережі: ввід імітуйте через `std::istringstream`, пояснюйте, що в реальній програмі там `std::cin`. Один файл `main.cpp`: заголовки, `.cpp` та CMake показуйте блоками `// фрагмент:`.
- **Детермінований вивід.** Без `time`, `random_device`, адрес і `sizeof`-залежного виводу (перевіряйте `static_assert`), без `unordered_*` у виводі без сортування, без залежності від планувальника потоків (синхронізуйте `join`, `future`, сортуйте результат).
- **Невизначену поведінку не запускайте.** Показуйте її текстом або фрагментом, а «аварія» дозволена лише з гарантованим результатом: `assert` (збирається без `NDEBUG`), `std::terminate` від необробленого винятку, `abort()`, `return 1`.
- Текст, що друкує програма, може бути українським (UTF-8); довжину рядків з кирилицею не перевіряйте (це байти).

## 3. Маркери блоків коду

Перший рядок-коментар блока (`//`): `// не компілюється: …` (має дати помилку компіляції), `// аварія: …` (ненульовий код завершення), `// фрагмент: …` (не запускається). Без маркера блок мусить успішно зібратися й завершитися з кодом 0. Приблизно кожен п'ятий приклад показує збій.

## 4. Норми

Ті самі, що в course-template.md (1.2 і 1.3): `easy` 20–50 слів, 6–7 абзаців теорії (≥1800 символів, усього 450–950 слів на урок), 3–5 прикладів, `note` 18–60 слів, `work` 28–60 слів, ровно 2 питання самоперевірки; в завданні ≥3 перевірки з `hint`, є перевірка виводу, `context` 15–46 слів, XP 15–60, заготовка запускається, але не проходить усіх перевірок, еталон проходить. У текстових полях дозволені лише теги `<code>`, `<b>`, `<i>`; `<`, `>`, `&` пишіть як `&lt;`, `&gt;`, `&amp;` (у C++ це шаблони: `std::vector&lt;int&gt;`).

## 5. Залежності

Базовий урок спирається лише на раніші базові; просунутий — на базові й раніші просунуті. Лямбди докладно в уроці 46, тож до нього у 27-му уроці (алгоритми) вводьте лише мінімальний синтаксис `[](int x) { return … }` одним абзацом.
