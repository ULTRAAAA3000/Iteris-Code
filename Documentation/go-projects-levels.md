# Go: проекты по ТЗ и уровни курса (базовый / продвинутый)

> Статус: реализовано на ветке `feature-go-projects` (19.11.2026). Пока только Go: так видно, как это выглядит, прежде чем переносить на другие языки.

## 1. Курс Go: 110 уроков, два уровня

- В курсе 110 уроков (`content/go/`, 12 глав). У 30 уроков стоит `adv: true`: это продвинутый уровень. Остальные 80 образуют базовый уровень.
- Номера уроков не меняются при переключении (`/lesson/go/54` всегда один и тот же урок), прогресс и ссылки сохраняются.
- **Базовый** уровень скрывает продвинутые уроки в списке курса, на «Моём пути», в боковом списке урока, в «Следующий / Предыдущий урок», в «Продолжить» и в процентах прогресса (считается по 80). **Продвинутый** показывает все 110.
- Уровень по умолчанию: базовый. Переключатель стоит на странице курса, на «Моём пути» и в каждом уроке; менять можно в любой момент. Продвинутый урок, открытый по прямой ссылке, остаётся доступным (на нём метка «продвинутый уровень»).
- Хранение: таблица `user_course_levels(user_id, course, level)` (миграция `0014_course_levels.sql`, также в `schema.sql` и `lib/schema.ts`). Нет строки: базовый. Читается вместе со структурой курсов (`GET /api/courses` → `levels`), меняется `POST /api/level { course, level }`. Уровни допустимы только для курсов, где есть уроки с `adv` (сейчас Go).
- Клиент: `src/data.ts` (`levelOf`, `inLevel`, `levelTotal`), `src/levels.ts` (переключатель, `levelProgress`, `nextInLevel`).

## 3. Как проверяется проект

1. Браузер получает проект через `GET /api/project?id=…`. Скрытый **harness** (код проверок) в ответ не попадает.
2. `POST /api/project-run { projectId, code }` собирает программу: код пользователя + harness (`lib/project-run.ts`), запускает её в Go Playground и разбирает строки `R<n> PASS` / `R<n> FAIL: причина`. Требование без строки (программа упала, зависла) считается невыполненным.
3. Если выполнены все требования и код завершения 0, сервер выдаёт подписанный `proof` (`lib/proof.ts`, привязан к пользователю, проекту и точному коду, 15 минут).
4. `POST /api/progress/complete` принимает «пройдено» для программного проекта только с таким `proof`, XP начисляется один раз.
5. Лимиты: 8 запусков в минуту и 300 в день на пользователя, код до 20000 символов.

Заготовка содержит все импорты harness и строки `var _ = fmt.Sprint` («не удаляйте»): импорты можно писать только в начале файла.

## 4. Тесты

- `tests/program-projects.test.mjs` запускает реальными `python3`, `javac`/`java`, `go`: эталон проходит все требования (код 0), заготовка компилируется и не проходит ни одного, harness не читает ввод/файлы/сеть, проекты стоят на базовых уроках.
- `tests/go-levels.test.mjs`: `/api/project` без harness, `/api/project-run` (Go Playground подменён), `proof` и XP в `complete`, `adv` и `levels` в `/api/courses`, `/api/level`.

## 5. Как добавить проект или перенести на другой язык

- Добавить объект в `content/projects/<язык>.ts` (тип `content/projects/program-types.ts`), эталон в `tests/solutions/<язык>-projects.mjs`, запустить `node tests/program-projects.test.mjs`.
- Другой язык: добавить его в `ProgramLang`, подключить runner в `/api/project-run` (сейчас `RUNNERS[p.lang]`), проверить, что уроки-якоря базовые. Для уровней у курса нужны уроки с `adv: true`.
