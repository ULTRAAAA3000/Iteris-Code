## 2. Что сделано в коде (17.11.2026)

- **Сессии:** в cookie добавлена версия `v`; `currentUser` сверяет её с `users.session_ver`. Файлы: `lib/session.ts`, `functions/api/auth/reset.ts`, `functions/api/auth/logout.ts` (`{ "all": true }`), кнопка в настройках профиля.
- **Жалобы:** `POST /api/report`, таблица `reports` (миграция `migrations/0012_security.sql`, сайт сам тоже создаёт её). Просмотр вручную: `npx wrangler d1 execute iteris-code --remote --command "SELECT * FROM reports ORDER BY created_at DESC"`.
- **Лимиты:** `progress/complete` (хранение, 600 в сутки), `run` (500 в сутки), `_middleware` (413 при теле больше 300 КБ).
- **Заголовки:** `build.mjs` пишет блок `/*` в `dist/_headers`. Полный `script-src` в CSP пока не включён (см. п. 5).
- **Файлы:** `static/.well-known/security.txt`, `.github/workflows/ci.yml`, `.github/dependabot.yml`.
- **Тесты:** `tests/security.test.mjs` (9 проверок).

## 3. Что включить вручную (Cloudflare) ✅ чек-лист

1. **Turnstile обязателен:** задать `TURNSTILE_SITE_KEY` и `TURNSTILE_SECRET_KEY` для Production и Preview. Без них формы входа и регистрации открыты ботам.
2. **WAF → Rate limiting:** правило на `/api/auth/*` (например, 20 запросов за 10 секунд с одного IP → блокировка на минуту) и на `/api/*` (например, 100 за 10 секунд). Бесплатный тариф даёт ограниченное число правил, главное правило ставим на `/api/auth/*`.
3. **Security → Bots → Bot Fight Mode:** включить.
4. **SSL/TLS:** режим Full (strict), Always Use HTTPS, минимальная версия TLS 1.2.
5. **Почта:** SPF, DKIM и DMARC для `iteris-code.org` (Resend покажет записи), чтобы письма не попадали в спам и домен нельзя было подделать. Создать ящик `privacy@iteris-code.org` (Email Routing).
6. **Доступ в Cloudflare:** двухфакторная защита на аккаунте Cloudflare, GitHub и Google владельца; отдельный ящик для входа.
7. **Секреты:** `SESSION_SECRET` не короче 32 случайных символов, менять при подозрении на утечку (все выйдут из аккаунтов). Токен GitHub из чата давно отозвать.
8. **Резервные копии D1:** включить/проверить Time Travel и раз в неделю выгружать `npx wrangler d1 export iteris-code --remote --output backup.sql`, хранить вне репозитория.
9. **Миграция:** `npx wrangler d1 execute iteris-code --remote --file=migrations/0012_security.sql` (сайт и сам добавит колонку и таблицу при первом запросе).
10. **Staging:** закрыть Cloudflare Access ([staging.md](staging.md)).

## 4. Что включить вручную (GitHub)

- **Settings → Branches → Branch protection для `main`:** требовать pull request и зелёную проверку `CI`, запретить force push и удаление ветки.
- **Settings → Code security:** включить Secret scanning, Push protection, Dependabot alerts.
- **Settings → Actions → General:** права токена по умолчанию «только чтение».
- Репозиторий публичный: уроки видны всем (Q8). Если уроки важны, сделать репозиторий приватным или вынести их.

## 5. Известные ограничения и что дальше

- **Результаты браузерных проверок (JS-задания, проекты) подделываемы:** можно отправить `passed: true`. Это ограничивает только XP, пока нет рейтингов и монет. **Перед этапом 5 (монеты, магазин) и лигами:** ввести суточный потолок наград и серверную проверку там, где возможно.
- **CSP с `script-src`:** сейчас в сайте есть inline-скрипты и Monaco с CDN; полный CSP нужно ввести после проверки в реальном браузере, сначала в режиме `Report-Only`.
- **Блокировка входа:** 10 неудачных попыток блокируют вход на почту на 15 минут (злоумышленник может мешать жертве). Смягчает Turnstile; позже: уведомление на почту.
- **Уведомления о входе и смене пароля** на почту: не сделаны.
- **Двухфакторная защита пользователей:** не сделана (для учебной платформы не первая очередь).
- **Мониторинг:** сейчас только логи Cloudflare; позже: счётчики ошибок 5xx/429, оповещения при скачке регистраций.
- **Админка и модерация** (этап 6): просмотр жалоб, блокировка пользователей, массовые действия. Сейчас жалобы смотрим вручную.
- **Анти-спам био:** простая проверка ссылок есть; словарь нежелательных слов не делали.

## 6. Если что-то случилось (план действий)

| Ситуация | Действия |
|---|---|
| Подозрение на утечку `SESSION_SECRET` или кражу cookie | Сменить `SESSION_SECRET` (все сессии станут недействительны), проверить логи Cloudflare, объявить пользователям при необходимости |
| Утечка базы данных | Сменить ключи (Google, GitHub, Resend, Turnstile), сменить секрет, уведомить ÚOOÚ **в течение 72 часов** и пользователей, если есть высокий риск (GDPR ст. 33–34) |
| Волна ботов (регистрации, письма) | Включить Under Attack Mode в Cloudflare, ужесточить правило rate limiting, временно отключить регистрацию по почте |
| Жалоба на профиль | Посмотреть `reports`; при нарушении закрыть профиль: `UPDATE users SET profile_public = 0 WHERE nick = '…'`, при повторе удалить или заблокировать |
| Вредный код в песочнице | Зависит от внешнего сервиса (Go Playground, Wandbox); при злоупотреблении временно отключить серверный запуск |
| Запрос пользователя на данные | Он может сам выгрузить и удалить аккаунт; иначе по письму на `privacy@iteris-code.org` в течение 30 дней |
| Сообщение об уязвимости | Приходит на адрес из `security.txt`; ответить, исправить, поблагодарить |
